HOW EACH FILM IS MADE

RESEARCH

Primary sources only — archives, official records, contemporaneous reporting. Every claim is logged with a citation in SOURCES.md.

SCRIPT

Narration written to the evidence, victims treated respectfully, and the killer's own claims never presented as confirmed fact.

ANIMATION

A deterministic SVG/canvas engine renders every frame from code — maps, timelines, cipher breakdowns and evidence graphics.

SOUND

Synthesized score and foley mixed under the narration, then mastered to broadcast loudness targets.

DELIVERY

Each film ships as a GitHub Release: full MP4, subtitles, poster, chapter timestamps and the complete source list.

REPRODUCIBLE

The whole film is data — script JSON, scene timeline, build script. Any film can be rebuilt from its folder in this repo.
